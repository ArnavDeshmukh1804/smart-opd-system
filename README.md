# Smart OPD Management System

A full-stack healthcare management system developed using Firebase, JavaScript, Twilio, and EmailJS.

## Features

- Patient Registration
- Appointment Scheduling
- QR Code Based Access
- Multi-Doctor Department System
- Lab Reports
- PDF Report Generation
- Email Notifications
- WhatsApp Notifications
- Analytics Dashboard
- Firebase Authentication
- Firebase Hosting
